================================================================================
SMART WARDROBE (ALCOVE) — COMPLETE RUNNING INSTRUCTIONS
================================================================================

1. SYSTEM REQUIREMENTS & PREREQUISITES
--------------------------------------
- Node.js (v18.x or v20.x recommended)
- Python (v3.9 or higher, for AI Engine)
- MongoDB (local instance running at mongodb://localhost:27017 or MongoDB Atlas URI)

2. DATABASE SETUP
-----------------
Option A: Local MongoDB
- Ensure your local MongoDB service is running on port 27017.
- Default connection URI: mongodb://localhost:27017/alcove

Option B: Remote / MongoDB Atlas
- Update `MONGODB_URI` in `backend/.env` with your Atlas connection string.

3. BACKEND SETUP & RUNNING (Node.js / Express)
----------------------------------------------
Step 1: Open a terminal and navigate to the backend folder:
        cd backend

Step 2: Install backend dependencies:
        npm install

Step 3: Verify Environment Variables in `backend/.env`:
        PORT=5000
        NODE_ENV=development
        MONGODB_URI=mongodb://localhost:27017/alcove
        JWT_SECRET=alcove_smart_wardrobe_secret_key_2026
        AI_ENGINE_URL=http://localhost:8000
        UPLOAD_DIR=uploads
        CORS_ORIGIN=http://localhost:3000,http://localhost:5173

Step 4: Start the backend server:
        npm run dev
        Backend will run on http://localhost:5000

4. AI ENGINE SETUP & RUNNING (Python Flask + Computer Vision)
--------------------------------------------------------------
Step 1: Open a new terminal window and navigate to the ai-engine folder:
        cd ai-engine

Step 2: Create and activate a Python virtual environment (recommended):
        python -m venv venv
        # Windows:
        venv\Scripts\activate
        # macOS / Linux:
        source venv/bin/activate

Step 3: Install dependencies:
        pip install -r requirements.txt

Step 4: Start the AI Engine server:
        python server.py
        AI Engine will run on http://localhost:8000

5. FRONTEND SETUP & RUNNING (React + Vite + TailwindCSS)
--------------------------------------------------------
Step 1: Open a new terminal window in the root project directory:
        cd "d:\Smart Waredrob"

Step 2: Install dependencies:
        npm install

Step 3: Start the Vite development server:
        npm run dev
        Frontend will be accessible at http://localhost:5173 (or http://localhost:3000)

6. QUICK START COMMAND SUMMARY (3 TERMINALS)
--------------------------------------------
Terminal 1 (Backend):    cd backend && npm run dev
Terminal 2 (AI Engine):  cd ai-engine && python server.py
Terminal 3 (Frontend):   npm run dev

7. FEATURE OVERVIEW & VERIFICATION
----------------------------------
- Login & Register: Authentication with JWT tokens stored in localStorage.
- Wardrobe (Dashboard): View user clothing items fetched dynamically from the database based on logged-in user.
- Add Item with Vision AI: Upload clothing photos. AI detects category, sub-type, primary/secondary colors, pattern, formality, and style.
- Outfit Generator: Recommends outfits matching occasion, weather, and style rules from user wardrobe. Clicking "Wear today" saves the outfit and logs it directly to your calendar wear history.
- Calendar (Wear History): Displays clothing items and outfits worn on specific dates, loaded dynamically from the database.
- Trip Planner: Generates smart packing capsules for destination and weather.
- Shared Outfits: Generate public outfit links (`/share/:id`) to get outfit feedback from friends.
